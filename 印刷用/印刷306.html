問1．ある店で、品物を1個200円で300個仕入れ、そのうち200個を1個280円で売った。残りは売れ行きが悪かったので値下げして売り出したところ、全部売り切れた。その結果、全体の利益は仕入総額の2割となった。値下げ後の1個の値段はいくらか。次の(1)〜(5)から1つ選べ。（6点）
(1) 120円   (2) 160円   (3) 240円   (4) 200円   (5) 190円
問1(正解:(2))
値下げ後の値段を y 円とおくと式が立てられるが、「仕入総額 → 目標の売上総額 → 値下げ分の売上」の順に金額を押さえていくほうが速い。

【手順1：仕入総額と売上総額】
仕入総額 = 200 × 300 = 60,000円
全体の利益は仕入総額の2割 → 60,000 × 0.2 = 12,000円
売上総額 = 60,000 + 12,000 = 72,000円

【手順2：値下げ分の売上】
280円で売った分の売上 = 280 × 200 = 56,000円
値下げして売った分の売上 = 72,000 − 56,000 = 16,000円

【手順3：値下げ後の値段】
値下げして売った個数 = 300 − 200 = 100個
y = 16,000 ÷ 100 = 160円

【別解：利益で考える】
280円で売った200個の利益 = (280 − 200) × 200 = 16,000円。全体の利益は12,000円だから、値下げ分の100個では 12,000 − 16,000 = −4,000円、すなわち1個につき40円の損失。よって 200 − 40 = 160円。

【選択肢の検討】（各値段での全体の利益）
・(1) 120円 → 利益 8,000円（仕入総額の13.3％）。値下げ額 280 − 160 との取り違え。不正解
・(2) 160円 → 利益 12,000円（仕入総額の2割）で条件と一致。正解
・(3) 240円 → 利益 20,000円。値下げ後も原価の2割の利益があると誤解した値。不正解
・(4) 200円 → 利益 16,000円。値下げしても原価は割らないと決めつけた値。不正解
・(5) 190円 → 利益 15,000円。利益率の基準を売上とし 60,000 ÷ 0.8 = 75,000円 から求めた値。不正解

【注意点】
「利益は仕入総額の2割」であって売上の2割ではない。もとにする量が仕入総額であることを必ず確認する。また、値下げ後の値段が原価200円を下回る（1個40円の損失）ことは何ら矛盾ではない。

したがって、正解は(2)である。
問2．ある店で、ある品物を500個仕入れ、原価の5割の利益を見込んで定価をつけた。まず定価で300個を売り、次に残りを定価から一定の割合で値引きして売ったところ150個が売れたが、50個は売れ残ったため廃棄した。その結果、全体の利益は仕入総額の26％にあたる13,000円となった。値引きした割合は定価の何割か。次の(1)〜(5)から1つ選べ。（6点）
(1) 1割引   (2) 4割引   (3) 1割5分引き   (4) 2割5分引き   (5) 2割引
問2(正解:(5))
値引き率を直接求めようとすると式が複雑になる。仕入総額と利益額の両方が与えられていることに着目し、まず1個の原価を確定させるのが最短の手順である。

【手順1：原価と定価を求める】
仕入総額 = 13,000 ÷ 0.26 = 50,000円、1個の原価 = 50,000 ÷ 500 = 100円
定価 = 100 × 1.5 = 150円

【手順2：売上総額を求める】
売上総額 = 仕入総額 + 利益 = 50,000 + 13,000 = 63,000円

【手順3：値引き販売分の売価を求める】
定価で売った分の売上 = 150 × 300 = 45,000円
値引きして売った分の売上 = 63,000 − 45,000 = 18,000円
値引き後の1個の売価 = 18,000 ÷ 150 = 120円

【手順4：値引きの割合を求める】
値引き額 = 150 − 120 = 30円、30 ÷ 150 = 0.2 → 定価の2割引

【検算】
利益 = (45,000 + 18,000) − 50,000 = 13,000円、13,000 ÷ 50,000 = 0.26 で条件と一致する。

【選択肢の検討】（各割引率での全体の利益）
・(1) 1割引（売価135円） → 利益 45,000 + 20,250 − 50,000 = 15,250円。不正解
・(2) 4割引（売価90円） → 利益 45,000 + 13,500 − 50,000 = 8,500円。不正解
・(3) 1割5分引き（売価127.5円） → 利益 45,000 + 19,125 − 50,000 = 14,125円。不正解
・(4) 2割5分引き（売価112.5円） → 利益 45,000 + 16,875 − 50,000 = 11,875円。不正解
・(5) 2割引（売価120円） → 利益 13,000円で条件と一致。正解

【最大の罠】
廃棄した50個を売れたものとして扱うと 18,000 ÷ 200 = 90円 → 4割引 となり(2)を選んでしまう。廃棄分は売上に寄与しないが、その原価5,000円は仕入総額に含まれたままである点に注意する。

したがって、正解は(5)である。
