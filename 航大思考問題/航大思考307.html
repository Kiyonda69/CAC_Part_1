問1 配点: 6点 / 目安時間: 3分
ある品物に、原価の3割の利益を見込んで定価をつけた。しかし売れ行きが悪かったので定価の2割引で売り出し、それでも売れ残った分については、さらにその値段の1割5分引きで売り切った。最後に売った分は、1個につき原価に対してどれだけの利益または損失となるか。
解説（正解: (5)）

問1（正解: (5)）


金額が一切与えられていないが、原価を1（または100円）とおけばすべての値段が原価の何倍かで表せるので、そのまま計算できる。


【手順1：定価】

原価を1とすると、定価 = 1 × (1 + 0.3) = 1.3


【手順2：定価の2割引】

1.3 × (1 − 0.2) = 1.3 × 0.8 = 1.04

この時点ではまだ原価の4％の利益がある。


【手順3：さらにその値段の1割5分引き】

1割5分引きの基準は定価ではなく、値下げ後の値段1.04である。

1.04 × (1 − 0.15) = 1.04 × 0.85 = 0.884


【手順4：損益の判定】

売価0.884 < 原価1 なので損失。

1 − 0.884 = 0.116 → 原価の11.6％の損失


【検算：原価1,000円として】

定価1,300円 → 2割引で1,040円 → その1割5分引きは 1,040 − 156 = 884円。

1,000 − 884 = 116円の損失で、116 ÷ 1,000 = 11.6％。一致する。


【選択肢の検討】

・(1) 4％の利益 → 2回目の値下げを忘れ、1.04で止めた値。不正解

・(2) 5％の損失 → 割合を 3割 − 2割 − 1割5分 = −5分 と足し引きした値。基準の異なる割合は加減できない。不正解

・(3) 11％の損失 → 1.04 から 0.15 をそのまま引いて0.89とした値。0.15は「1.04の15％＝0.156」でなければならない。不正解

・(4) 15.5％の損失 → 2つの値引きをまとめて定価から引き、1.3 × (1 − 0.2 − 0.15) = 0.845 とした値。不正解

・(5) 11.6％の損失 → 1.3 × 0.8 × 0.85 = 0.884 と順に掛けた値で条件と一致。正解


【最大の罠】

「2割引の後にさらに1割5分引き」は合計3割5分引きではない。値引きの基準（もとにする量）が定価から値下げ後の値段へ移っているため、0.8と0.85を掛け合わせる必要がある。実際 0.8 × 0.85 = 0.68 であり、定価からは3割2分引きに相当する。


したがって、正解は(5)である。

問2 配点: 6点 / 目安時間: 5分
ある店では、どの商品についても「定価に対して2割5分の利益が出る」ように定価を定めている。この店である商品を300個仕入れ、この方針で定価をつけて売り出したところ、一部は定価で売れ、残りはすべて定価の4割引で売れて売れ残りはなかった。その結果、全体の利益は仕入総額の2割となった。定価の4割引で売れた個数は何個か。
解説（正解: (2)）

問2（正解: (2)）


原価も定価も個数の内訳も与えられていないが、定価を1とおくと最後に定価が約分で消えるため、個数だけが残って求まる。まず「定価に対して2割5分の利益」という表現の意味を正しくつかむことが出発点である。


【手順1：原価は定価の何倍か】

利益の基準が原価ではなく定価であることに注意する。

定価 − 原価 = 定価 × 0.25 なので、原価 = 定価 × (1 − 0.25) = 定価の0.75倍

定価を1とすると、原価は0.75。


【手順2：仕入総額と売上総額】

仕入総額 = 0.75 × 300 = 225

全体の利益は仕入総額の2割 → 225 × 0.2 = 45

売上総額 = 225 + 45 = 270


【手順3：個数の方程式】

4割引で売れた個数を x 個とすると、定価で売れたのは (300 − x) 個、4割引の売価は 1 × 0.6 = 0.6 だから

(300 − x) × 1 + x × 0.6 = 270

300 − 0.4x = 270 → 0.4x = 30 → x = 75個


【別解：値引きによる売上の減少で考える】

全部が定価で売れたときの売上は300。実際は270だから、値引きによって30だけ減った。1個を4割引にすると売上は定価の0.4だけ減るので、30 ÷ 0.4 = 75個。


【検算：定価400円（原価300円）として】

仕入総額 = 300 × 300 = 90,000円。売上 = 225個 × 400 + 75個 × 240 = 90,000 + 18,000 = 108,000円。

利益 = 18,000円 = 90,000 × 0.2 で、仕入総額の2割と一致する。


【選択肢の検討】

・(1) 30個 → 「2割5分の利益」を原価に対するものと誤解し、定価 = 原価 × 1.25 として解いた値。不正解

・(2) 75個 → 上記の計算どおりで条件と一致。正解

・(3) 50個 → 「4割引」を「定価の4割の値段で売る」と読み違えた値。4割引の売価は定価の6割である。不正解

・(4) 120個 → 値引き率を2割5分引きと取り違えた値。2割5分は利益率であって値引き率ではない。不正解

・(5) 225個 → 定価で売れた個数。問われているのは値引きして売れた個数である。不正解


【最大の罠】

「定価に対して2割5分の利益」は原価の2割5分増しではない。原価 = 定価 × 0.75 であり、これを原価 × 1.25 = 定価（原価基準）と取り違えると(1)の30個に導かれる。ちなみに定価は原価の 1 ÷ 0.75 ≒ 1.33倍、すなわち原価の約3割3分増しにあたる。


したがって、正解は(2)である。
